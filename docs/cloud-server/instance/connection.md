# اتصال به ابرک

پس از ساخت ابرک خود در پنل کاربری، با توجه به سیستم‌عامل ابرک می‌توانید از طریق SSH یا Remote Desktop به ابرک متصل شوید. در این راهنما شیوه‌ی اتصال به ابرک را بررسی خواهیم کرد.

## اتصال به ابرک از طریق SSH

SSH روشی برای اتصال به ترمینال سیستم‌عامل‌های لینوکسی است. در این روش شما می‌توانید با وارد کردن آدرس IP سرور به ترمینال آن متصل شوید. برای این کار، می‌توان از نرم‌افزارهای مختلفی استفاده کرد که یکی از آن‌ها PuTTY است و در ویندوز کاربرد دارد. کافی است نرم‌افزار PuTTY را دانلود و آدرس IP سیستمی که از پروتکل SSH پشتیبانی می‌کند، وارد کنید تا بتوانید به آن متصل شوید. از سیستم‌های لینوکسی نیز به‌راحتی می‌توانید با تایپ دستور:

```
ssh ABRAK_IP_ADRESS
```

به ابرک خود SSH بزنید. پس از ساخت ابرک در پنل کاربری ابر آروان، برای اتصال به آن، دو روش وجود دارد:

* استفاده از نام کاربری و رمز عبور ارسالی به ایمیل شما
* استفاده از کلید (Key)

### اتصال به ابرک با نام کاربری و رمز عبور

نام کاربری پیش‌فرض برای نخستین اتصال به ابرک متناسب با نوع سیستم‌عامل در زیر آمده است:

| **نام سیستم‌عامل** | **نام کاربری پیش‌فرض** |
| --- | --- |
| Ubuntu | ubuntu |
| Debian | debian |
| Redhat | redhat |
| Centos | centos |
| Cirros | cirros |

برای ارتباط SSH با ابرک می‌توان از ابزارهای مختلفی استفاده کرد. یکی از این ابزارها، نرم‌افزار PuTTY است. همان‌طور که در تصویر نشان داده شده است، از منوی سمت چپ، گزینه‌ی Session را انتخاب کنید، سپس برای برقرای ارتباط SSH آی‌پی ابرک خود را در بخش (Host name (or IP Address وارد کنید و تیک گزینه‌ی SSH را بزنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/putty.png)

پس از نخستین اتصال، سیستم از شما تغییر رمز عبورِ کاربری که با آن متصل شده‌اید را درخواست می‌کند. ابتدا باید رمز ورودی که به وسیله‌ی ایمیل دریافت کرده‌اید را وارد کنید، سپس رمز عبور جدید خود را وارد کنید. پس از انجام این کار، رمز عبور پیش‌فرض تغییر خواهد کرد.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/reset-password.png)

### فعال‌سازی کاربر root

در ابتدا یوزر root ابرک‌های لینوکسی غیرفعال است و می‌توانید پس از نخستین اتصال، دسترسی با کاربر root را فعال کنید و در ارتباط‌های بعدی، مستقیم و با این Username به ابرک خود متصل شوید.

برای انجام این کار با ورود به ابرک، ابتدا سیستم از شما تغییر رمز عبور کاربری که با آن متصل شده‌اید را درخواست می‌کند. پس از وارد کردن رمز عبور جدید و اتصال مجدد به ابرک، از دستور زیر برای ورود به محیط کاربری root استفاده کنید:

```
sudo –i
```

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/sudo.png)

در گام بعد، با استفاده از دستور زیر رمز عبوری را برای کاربر root تنظیم کنید:

```
passwd
```

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/passwd.png)

مرحله‌ی بعد، پس از وارد کردن رمز عبور جدید، تغییر تنظیمات پیش‌فرض فایل sshd\_config است. برای انجام این کار، از دستور زیر برای ورود و دستیابی به محتویات این فایل استفاده کنید:

```
nano /etc/ssh/sshd_config
```

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/sshconfig.png)

در گام بعد، مقدار PermitRootLogin را در این فایل به yes تغییر دهید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/permitroot.png)

سپس برای ذخیره‌ی این تنظیمات جدید و خروج از فایل، Ctrl+X، سپس Y و نهایتن Enter را بزنید. آخرین اقدام مورد نیاز، راه‌اندازی مجدد سرور SSH است. برای انجام این کار از دستور زیر استفاده کنید:

```
service ssh restart
```

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/restartssh.png)

پس از گذراندن این مراحل، می‌توانید در اتصال‌های بعدی، مستقیم با کاربر root به ابرک خود دسترسی ssh داشته باشید.

### اتصال به ابرک با کلید SSH

در ابر آروان برای حفظ هرچه بیش‌تر امنیت کاربران، با انتخاب «کلید SSH» هنگام ساخت ابرک، هیچ‌گونه رمز عبوری پس از ساخت ابرک جدید تولید نمی‌شود. به‌همین دلیل، هنگام ساخت ابرک، کابران باید یک کلید که با نام «کلید عمومی» شناخته می‌شود را وارد کنند تا بعد از راه‌اندازی ابرک، بتوانند به‌وسیله‌ی کلید دیگری که «کلید خصوصی» نامیده می‌شود و فقط در اختیار خودشان است، به ابرک SSH بزنند.

ما در زیرساخت ابری خود برای اطمینان از حفظ امنیت کاربران، از روش رمزنگاری عمومی و خصوصی برای اتصال اولیه‌‌ی کاربران استفاده می‌کنیم. بنابراین شما حتمن باید قبل از ایجاد ابرک، یک کلید عمومی و خصوصی مخصوص خود داشته باشید تا هنگام ایجاد ابرک بتوانید کلید عمومی خود را وارد سیستم کنید و بعد از بالا آمدن ابرک بتوانید با «کلید خصوصی» به آن متصل شوید.

#### شیوه‌ی ایجاد کلید عمومی و خصوصی

برای این کار می‌توانید از پنل ابر آروان استفاده کنید. این کار به‌راحتی مراحل زیر است.

وارد پنل کاربری ابر آروان شوید و به قسمت امنیت در منوی سرور ابری رفته و سپس "کلید SSH" را انتخاب کنید. سپس روی دکمه‌ی"ساخت SSH Key" کلیک کنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/key.png)

در صفحه‌ی باز شده اطلاعات مربوط به کلید عمومی خود را وارد کرده و یا آن را به‌وسیله‌ی Drag and Drop آپلود کنید.

> اگر از پیش کلید عمومی ندارید می‌توانید روی دکمه‌ی «ایجاد کلید جدید» کلیک کنید تا کلید به‌شکل خودکار ساخته شود.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/keyc.png)

بعد از این کار به‌شکل خودکار کلید عمومی در بخش مربوطه نمایش داده می‌شود . دو لینک با فرمت ‎.pem‎ و ‎.ppk‎ برای دانلود کلید خصوصی شما آماده می‌شود. شما می‌توانید از فایل ‎.ppk برای نرم‌افزار putty و از فایل ‎.pem برای اتصال از طریق سیستم‌های لینوکسی استفاده کنید.

در نهایت یک نام برای کلید خود انتخاب کنید و دکمه‌ی ذخیره را بزنید. اکنون هنگام ساخت ابرک جدید، کلید جدید را مشاهده می‌کنید.

گفتنی است که اگر از قبل کلید خصوصی خود را دارید، می‌توانید به روش‌های مختلف آن را در ابر آروان آپلود کنید. یکی از راحت‌ترین روش‌ها استفاده از روش بیان شده در بالا و آپلود کلید خود در بخش "SSH Public Key" و سپس انتخاب یک اسم و ذخیره است. تمامی این کارها را به‌شکل مستقیم از قسمت ساخت ابرک جدید هم می‌توانید انجام دهید.

#### شیوه اتصال به ابرک با کلید

حال که کلید مخصوص خود را ایجاد و به‌وسیله‌ی آن ابرک را نیز ایجاد کرده‌اید، باید بتوانید به آن متصل شوید. برای این کار نرم‌افزار Putty را باز کرده و مطابق شکل زیر عمل کنید.

ابتدا مطابق تصویر بالا، آدرس IP ابرک را که درپنل ابر آروان قابل مشاهده است، وارد کنید.

سپس به‌ترتیب وارد گزینه‌های زیر شده و در نهایت با انتخاب دکمه‌ی Browse کلید خصوصی خود را انتخاب کنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/puttykey.png)

در آخر روی دکمه‌ی Open کلیک کنید و منتظر اتصال به ابرک خود شوید.

## اتصال به ابرک از طریق Remote Desktop

برای نخستین اتصال به ابرک‌های ویندوزی، نیاز است به وسیله‌ی کنسول به آن متصل شوید.

برای انجام این‌کار در پنل کاربری ابر آروان به بخش **سرور ابری**، سپس **لیست ابرک‌ها** بروید و روی گزینه‌ی **کنسول** از منوی مقابل نام ابرک کلیک کنید.

پس از انتخاب این گزینه، با پنجره‌ای مشابه تصویر زیر روبه‌رو می‌شوید. با زدن دکمه‌ی **Ctrl+Alt+Del** می‌توانید به محیط login ویندوز وارد شوید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/win.png)

پس از ورود به صفحه‌ی login، نخستین درخواست سیستم از شما تغییر رمز عبور است.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/win1.png)

پس از ورود رمز عبور دل‌خواه و تایید آن، شما می‌توانید وارد محیط ویندوز شوید. دقت داشته باشید که رمز عبور باید Complex (ترکیبی از حروف بزرگ و کوچک، کاراکترهای مختلف و اعداد) باشد.

حال که رمز عبور تعیین‌شده است، شما می‌توانید در دسترسی‌های بعدی از سرویس **Remote Desktop Connection** ویندوز برای اتصال به ابرک خود استفاده کنید. ابتدا مطمین شوید که این سرویس روی ویندوز سرور ابرک فعال است. برای انجام این کار از منوی **Start**، گزینه‌ی **Server Manager** را باز و از منوی سمت چپ روی گزینه‌ی **Local Server** کلیک کنید. در پنجره‌ی باز شده باید روبه‌روی عبارت **Remote Desktop**، گزینه‌ی **Enabled** درج شده باشد.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/remote.png)

اگر روبه‌روی این عبارت disabled درج شده بود، روی آن کلیک کنید و در پنجره‌ی باز شده تیک گزینه‌ی **Allow remote connections to this computer** را بزنید و روی **OK** کلیک کنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/remotee.png)

پس از انجام این تنظیمات روی ابرک، می‌توانید با کمک Remote Desktop به آن متصل شوید.

#### Remote Desktop Connection

برای دسترسی به ابرک با Remote Desktop، کلید‌های ترکیبی ویندوز و R را فشار دهید و در محیط Run عبارت .**mstsc** را بنویسید.

در پنجره‌ی باز شده آدرس IP ابرک خود که در پنل کاربری ابر آروان در بخش **لیست ابرک‌ها**، روبه‌روی ابرک شما نوشته شده است را وارد کنید. سپس گزینه‌ی **Show Options** را بزنید. در بخش **Username**، عبارت **Administrator** را وارد کنید. هم‌چنین می‌توانید برای ذخیره‌ی اطلاعات login، تیک گزینه‌ی **Allow me to save credentials** را نیز بزنید. به این ترتیب در دسترسی‌های بعدی با کمک Remote Desktop، نیازی به ورود نام کاربری و رمز عبور نیست. درنهایت روی **connect** کلیک کنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/rdp.png)

در گام بعد، در پنجره‌ی باز شده، رمز عبوری که هنگام نخستین اتصال به ابرک انتخاب کرده‌اید، در قسمت Password وارد کنید و OK را بزنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/rdp1.png)

اگر پس از زدن OK پنجره‌ای همانند تصویر زیر به شما نشان داده شد، تیک گزینه‌ی **Don't ask me again for connections to this computer** را بزنید و روی **Yes** کلیک کنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/abrak/connection/rdp2.png)

به این ترتیب شما می‌توانید با استفاده از RDP به ابرک خود متصل شوید.
