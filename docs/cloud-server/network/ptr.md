# رکورد PTR ابرک

برخلاف رکورد A که مسوول نگاشت یک Hostname به یک آدرس IP است، رکورد PTR مسوول نگاشت یک آدرس IP به یک Hostname است. از این رکورد برای Reverse DNS Lookup استفاده می‌شود.

به‌شکل خلاصه و ساده، عملکرد Reverse DNS دقیقن مخالف کاری است که DNS انجام می‌دهد. در DNS هر نام دامنه‌ به یک آدرس IP نگاشت می‌شود، پس هنگامی‌که درخواستی مبنی‌بر دسترسی به یک سایت به یک سرور DNS می‌رسد، سرور DNS در پاسخ آدرس IP آن دامنه را در قالب یک رکورد A ارسال می‌کند. اما در Reverse DNS هر آدرس IP به یک نام دامنه نگاشت می‌شود، پس Reverse DNS در پاسخ به یک درخواست، رکورد PTR را برمی‌گرداند.

معمولن Reverse DNS Lookup را ایمیل سرورها انجام می‌دهند. اگر ایمیل سرورها، ایمیلی را از سوی دامنه‌ای دریافت کنند که از Reverse Lookup پشتیبانی نمی‌کند، آن ایمیل را اسپم در نظر می‌گیرند.

## شیوه تنظیم رکورد PTR در پنل کاربری ابر آروان

برای تنظیم رکورد PTR، در پنل کاربری ابر آروان به پنل **سرور ابری**، بخش **شبکه‌ها** بروید. در این صفحه و از قسمت **IP اینترنتی** زیرشبکه‌ای که ابرک شما در آن قرار دارد را پیدا و روی دکمه‌ی **افزودن رکورد PTR** کلیک کنید. سپس در بخشی که باز می‌شود، رکورد PTR خود را وارد و روی تیک سبز رنگ کلیک کنید. به این ترتیب رکورد PTR دامنه‌ی شما ثبت می‌شود.
