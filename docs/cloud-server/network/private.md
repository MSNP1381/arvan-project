# شبکه خصوصی

با استفاده از قابلیت شبکه‌ی خصوصی در سرور ابری آروان، می‌توانید بین ابرک‌های موجود در یک دیتاسنتر ارتباط ایجاد کنید و به این ترتیب، سناریوها و راهکارهای پیشرفته‌ای را پیاده‌سازی کنید.

## ایجاد شبکه خصوصی

برای ایجاد یک شبکه‌ی خصوصی، پس از ورود به بخش شبکه‌ها در پنل کاربری سرور ابری، روی گزینه‌ی شبکه‌ی خصوصی کلیک کنید و در ادامه گزینه‌ی ایجاد شبکه خصوصی را انتخاب کنید.

![](https://s3.ir-thr-at1.arvanstorage.ir/arvandocs/cloudserver/network/network/private.png)

در صفحه‌ی پیش رو، اطلاعات مورد نیاز را وارد کنید. این اطلاعات شامل موارد زیر می‌شوند.

![](https://arvandocs.s3.ir-thr-at1.arvanstorage.ir/cloudserver/network/private-network/network-details.png)

### نام شبکه

در این بخش برای شبکه‌ی خصوصی جدیدی که می‌خواهید ایجاد کنید، یک نام وارد کنید. هر نامی در این بخش قابل انتخاب است.

### اطلاعات شبکه

در این بخش یک سابنت برای شبکه‌ی خصوصی تعریف کنید. نکته‌ی مهم این است که هنگام ساخت شبکه‌ی جدید باید دقت کنید حتمن برای Subnet، نشانی Gateway وارد کنید. این نشانی می‌تواند هر نشانی در بازه‌ی IP که خودتان مشخص کرده‌اید باشد. برای نمونه، اگر هنگام ساخت یک شبکه‌ی خصوصی جدید، Subnet Range را 10.0.0.0/24 داده باشید، نشانی Gateway می‌تواند 10.0.0.1 یا هر عددی در این Range باشد. به این ترتیب امکان استفاده از IP شناور را خواهید داشت.

هم‌چنین با انتخاب گزینه‌ی تنظیمات بیش‌تر، می‌توانید تنظیمات پیشرفته‌تری را برای شخصی‌سازی شبکه‌ی خصوصی خود انجام دهید. این تنظیمات شامل موارد زیر هستند:

### Gateway

ابرک‌هایی که در یک شبکه‌ی خصوصی قرار می‌گیرند به‌شکل پیش‌فرض فاقد اینترنت هستند. اگر در آینده نیاز به اینترنت داشته باشند، باید یک IP شناور برای این ابرک‌‌ها تهیه شود. اما لازمه‌ی استفاده از IP شناور دارا بودن Gateway است، پس توصیه می‌شود این گزینه را فعال نگه دارید.

هم‌چنین در بخش Gateway یک نشانی IP دل‌خواه را به‌عنوان Gateway وارد کنید. فقط توجه کنید که این آدرس باید در رنجی باشد که در بخش نشانی IP وارد کرده‌اید.

### رنج DHCP

اگر بخواهید ابرک‌هایی که در این شبکه قرار می‌گیرند به‌شکل خودکار IP دریافت کنند، می‌توانید یک بازه از IP که برای این شبکه در نظر گرفته‌اید را وارد کنید تا به‌شکل خودکار به ابرک‌ها واگذار شود.

### آدرس DNS

در این بخش می‌توانید نشانی یک NameServer شخصی یا عمومی مانند 8.8.8.8 را وارد کنید تا به‌شکل خودکار به ابرک‌ها اعمال شود.

در انتها و پس از انجام تنظیمات روی گزینه‌ی ایجاد شبکه کلیک کنید تا شبکه‌ی موردنظر با تنظیمات انجام شده ساخته شود.

## اتصال ابرک به شبکه خصوصی

برای اتصال ابرک به یک شبکه، روی گزینه‌ی «تنظیمات شبکه‌ خصوصی ابرک‌ها» در مقابل نام شبکه‌ی مورد نظر کلیک کنید.

![](https://arvandocs.s3.ir-thr-at1.arvanstorage.ir/cloudserver/network/private-network/connect.png)

سپس ابرک‌های مدنظر خود را انتخاب ‌کنید. با انجام تنظیمات مربوط به اضافه شدن ابرک به شبکه، حالا می‌توانید از درون هر یک از این ابرک‌ها سایر ابرک‌هایی که در این شبکه قرار دارند را Ping کنید. به این ترتیب شما می‌توانید سناریو‌های مختلف را طراحی و اجرا کنید.
